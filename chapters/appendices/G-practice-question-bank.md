## 📖 Part 3 — 84 Bonus Questions (for the least-practised objectives)

### Objective 1.3 — Change Management

**1.** In many organizations, which group formally reviews and approves proposed changes?
A. Change Advisory Board  B. Red team  C. Audit committee  D. Help desk

**2.** Which document gives step-by-step instructions so a routine change is performed the same way every time?
A. Risk register  B. MOU  C. Standard operating procedure  D. Threat feed

**3.** Which change management element names the person accountable for a change and its outcome?
A. Ownership  B. Stakeholders  C. Maintenance window  D. Test results

**4.** A new application server will be blocked unless firewall rules are updated as part of the change. Which technical implication is this?
A. Downtime  B. Legacy application  C. Version control  D. Allow list / deny list updates

**5.** Upgrading a shared library breaks an old internal application that depends on the previous version. Which technical implications were overlooked?
A. Maintenance window  B. Legacy applications and dependencies  C. Ownership  D. Restricted activities

**6.** During an incident, responders are misled because a recent change was never reflected in the network diagram. Which step was skipped?
A. Backout plan  B. Impact analysis  C. Approval  D. Updating diagrams (documentation)

**7.** A critical, actively exploited vulnerability needs a patch tonight. How should change management handle it?
A. Skip all records  B. Use the emergency change process: expedited approval, then full documentation afterwards  C. Wait for next quarter's CAB meeting  D. Let any administrator patch without telling anyone

**8.** Which group must be informed or consulted because a change affects their department's work?
A. Auditors only  B. Threat actors  C. Stakeholders  D. Processors

### Objective 2.1 — Threat Actors & Motivations

**9.** An attacker with little skill launches attacks using scripts downloaded from the internet. Which actor is this?
A. Nation-state  B. APT  C. Organized crime  D. Unskilled attacker

**10.** An employee sells customer records to a competitor. What is the MOST likely motivation?
A. War  B. Financial gain  C. Ethical  D. Philosophical beliefs

**11.** A state-sponsored group has large budgets, custom tools and dedicated teams. Which attributes describe it?
A. Low resources, low sophistication  B. Internal, low funding  C. High resources/funding and high sophistication  D. Shadow IT

**12.** During a military conflict, a government's hackers disrupt the enemy's power grid. Which motivation BEST fits?
A. Blackmail  B. Revenge  C. War  D. Ethical

**13.** A security researcher discovers a flaw and reports it privately to the vendor. Which motivation is this?
A. Ethical  B. Espionage  C. Data exfiltration  D. Disruption/chaos

### Objective 4.1 — Security Techniques for Computing Resources

**14.** Which components does WPA3-Enterprise use to authenticate each user individually?

**17.** A company phone is stolen. Which MDM capability protects its data?

**18.** Which technique can find hard-coded passwords in source code before the application is built?
A. Static code analysis  B. Load balancing  C. NetFlow  D. Degaussing

### Objective 4.2 — Asset Management

**19.** Who is accountable for an asset's protection, access approvals and eventual disposal?
A. Any user  B. The vendor  C. The asset owner  D. The auditor

**20.** A company buys hardware only from approved suppliers that meet its security requirements. Which asset lifecycle stage is this?

**24.** A network scan reveals devices that aren't in the inventory. Which activity found them?

A. Clear  B. Archive  C. Destroy  D. Purge
